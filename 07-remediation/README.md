# 07 — Remediation

Once a finding in `06-findings/` is fixed and you've independently verified
the fix actually closes the gap (not just "a patch was applied"), summarize
it here.

## Template per entry
```
## FIX-XXXX: <title> (closes FINDING-XXXX)
- Date remediated:
- What changed:
- How it was verified: (re-ran the original reproduction steps, result)
```

Keep full technical reproduction detail in the original finding file, not
here — this folder is a status/audit trail, not a duplicate write-up.
